# Portfolio-Optimization-using-complex-networks
A portfolio can be improved if we can filter through the assets in an efficient way to find the best lot of assets for your portfolio. To create a high return portfolio with lower downside potential, diversification is important. 
We achieve the diversification by selecting lower centrality assets.
We vary N (Number of assets in portfolio), use different types of centralities and quantitatively analyze the model using parameters such as sharpe ratio, turnover volume and break even transaction costs.
( Reproduced results from the paper - Portfolio optimization based on network centralities: Which centrality is better for asset selection during global crises? )
